# mode_transitions.txt -- role-level link diff per mode transition (from -> to).
# Regenerated for the instrument bus. Roles are the LinkRole values in
# AudioGraphManager::desiredRoles(); sever = in FROM only, create = in TO only, keep = both.
#
# Every audible source (MEL/DRUM/VOC/MIC/SL/VOL *_HP roles) links ONLY to instrument-bus:in_1/in_2.
# BUS_SINK (instrument-bus:out_1/2 -> configured sink) is in every mode, so it is always 'keep':
# the single path from the instrument into the sink never changes during a transition.
# *_SL roles feed SooperLooper from the PRE-bus sources; the bus output is never linked to SL.
# Mode 6 (Talkbox) routing is removed; a leftover Talkbox mode value uses the default list
# (same as 4_BreathOctave).
